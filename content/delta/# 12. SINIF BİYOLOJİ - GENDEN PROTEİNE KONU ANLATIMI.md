### 2. DNA REPLİKASYONU (ÇOĞALTILMASI)

**Süreç:**

1. **Helikaz** enzimi DNA'yı açar (hidrojen bağlarını koparır)
2. **Replikasyon çatalı** oluşur
3. **DNA polimeraz** yeni zinciri sentezler
4. **Yarı-koruyucu replikasyon**: Her yeni DNA'da 1 eski + 1 yeni zincir

**ÖNEMLİ:**

- DNA polimeraz sadece **5' → 3'** yönde sentez yapar
- **Öncü zincir (Leading):** Sürekli sentezlenir
- **İzleyen zincir (Lagging):** Okazaki fragmanları halinde sentezlenir
- **Primazز** RNA primer yapar (başlangıç noktası)
- **Ligaz** fragmanları birleştirir

**Baz Eşleşme Kuralı:**

- A ↔ T
- G ↔ C
- Antiparalel: 5' uç → 3' uç karşısına gelir

**ÖRNEK:**

```
Verilen DNA: 5' - ATGCCG - 3'
Tamamlayıcı: 3' - TACGGC - 5'
```

### 3. PROTEİN SENTEZİ

#### A) TRANSKRİPSİYON (mRNA Sentezi)

**Yer:** Çekirdek (ökaryotlarda)

**Süreç:**

1. **RNA polimeraz** DNA'ya bağlanır (promoter bölgesi)
2. DNA açılır (sadece kalıp zincir okunur)
3. DNA kalıbından mRNA sentezlenir (5' → 3' yönde)
4. Terminatör bölgede durur

**Baz Eşleşmesi (DNA → mRNA):**

- DNA'da A → mRNA'da U
- DNA'da T → mRNA'da A
- DNA'da G → mRNA'da C
- DNA'da C → mRNA'da G

**ÖRNEK:**

```
DNA kalıp:  3' - TACGCAATG - 5'
mRNA:       5' - AUGCGUUAC - 3'
```

**ÖKARYOTLARDA RNA İŞLEME:**

- **5' Cap eklenir:** Koruma
- **Poly-A kuyruğu:** mRNA kararlılığı
- **Splicing:** İntronlar kesilir, eksonlar birleşir

```
Pre-mRNA: Ekson1-İntron1-Ekson2-İntron2-Ekson3
Olgun mRNA: Ekson1-Ekson2-Ekson3
```

---

#### B) TRANSLASYON (Protein Sentezi)

**Yer:** Ribozom (sitoplazma)

**Genetik Kod:**

- **Kodon:** mRNA'da 3 nükleotid = 1 aminoasit
- **64 kodon, 20 aminoasit**
- **Başlangıç kodonu:** AUG (Metiyonin)
- **Stop kodonları:** UAA, UAG, UGA (aminoasit kodlamaz)

**Süreç:**

1. mRNA ribozoma bağlanır
2. **tRNA** antikodon ile kodon eşleşir
3. tRNA aminoasit taşır
4. **Peptit bağı** oluşur (ribozom katalizler)
5. Polipeptit zinciri uzar
6. Stop kodon → sentez biter

**AMİNOASİT HESAPLAMA:**

```
mRNA: 5' - AUGCGUUACUAAGGC - 3'
Kodonlar: AUG - CGU - UAC - UAA - GGC
          Met - Arg - Tyr - STOP - (okunmaz)
Aminoasit sayısı: 3 (Stop aminoasit değil!)
```

**Formül:**

- mRNA nükleotid sayısı ÷ 3 = Kodon sayısı
- Kodon sayısı - 1 (stop) = Aminoasit sayısı
- Eğer UTR bölgeler varsa onları çıkar!

### 4. MUTASYONLAR

#### Nokta Mutasyonları (Tek Nükleotid)

**1. Silent (Sessiz) Mutasyon:**

- Kodon değişir AMA aminoasit değişmez
- Genetik kodun dejenere olması sayesinde
- Örnek: AAA → AAG (Her ikisi de Lizin)

**2. Missense Mutasyon:**

- Kodon değişir → Farklı aminoasit
- Protein fonksiyonu değişebilir
- Örnek: Orak hücreli anemi (GAG → GUG, Glu → Val)

**3. Nonsense Mutasyon:**

- Kodon → Stop kodona dönüşür
- Protein kısa kalır (genelde zararlı)
- Örnek: AAA → UAA

#### Çerçeve Kayması (Frameshift)

**Delesyon (Silinme):**

```
Orijinal: AUG-CCG-UAC-GGG
Silinme:  AUG-CGU-ACG-GG? (Tüm kodonlar kayar!)
```

**İnsersiyon (Ekleme):**

- Nükleotid eklenir, tüm çerçeve değişir

**EN ZARARLI MUTASYON TİPİ:** Frameshift (Çünkü tüm proteini değiştirir)

### 5. GENETİK MÜHENDİSLİĞİ

#### Temel Araçlar

**1. Restriksiyon Enzimleri (Restriksiyon Endonükleaz):**

- DNA'yı belirli dizilerden keser
- "Moleküler makas"
- Örnek: EcoRI, BamHI
- Yapışkan uçlar (sticky ends) oluşturur

**2. Ligaz Enzimi:**

- DNA parçalarını birleştirir
- "Moleküler yapıştırıcı"

**3. Plazmit:**

- Bakterilerdeki küçük, dairesel DNA
- **Vektör** olarak kullanılır (gen taşıyıcı)
- Özellikleri:
  - Kolay izole edilir
  - Replike olur
  - Antibiyotik direnç geni taşıyabilir

**4. Ters Transkriptaz:**

- mRNA'dan cDNA (tamamlayıcı DNA) yapar
- İnsan genlerinde intron var, bakteride yok
- Bu yüzden mRNA → cDNA → Bakteriye

#### Gen Aktarımı Süreci

```
1. İNSAN HÜCRESİ
   ↓ İzolasyon
2. mRNA (insülin geni)
   ↓ Ters transkriptaz
3. cDNA (intron yok)
   ↓ Restriksiyon enzimi
4. Kesilen gen + Kesilen plazmit
   ↓ Ligaz
5. Rekombinant plazmit
   ↓ Transformasyon
6. BAKTERİ (insülin üretir)
```

**Seleksiyon:**

- Plazmite **antibiyotik direnç geni** eklenir
- Antibiyotikli ortamda sadece gen almış bakteriler yaşar

### 7. İLERİ TEKNOLOJİLER

#### CRISPR-Cas9

**Nedir?**

- "Genetik makas" sistem
- Hedefli gen düzenleme

**Bileşenler:**

- **Cas9:** DNA kesen enzim
- **sgRNA:** Hedef DNA'yı bulan kılavuz RNA
- **Donor DNA:** Yerine konulacak DNA

**Avantajları:**

- Hızlı, ucuz, kolay
- Çok spesifik
- Birden fazla gen değiştirilebilir

**Uygulamalar:**

- Kanser tedavisi (T hücre modifikasyonu)
- Kistik fibrozis tedavisi
- HIV dirençli hücreler
- Sıtma taşıyan sivrisineklerin kontrolü

#### Etik Sorunlar

**Germline Editing vs Somatic Editing:**

- **Somatic:** Vücut hücrelerinde, sadece bireyi etkiler
- **Germline:** Üreme hücrelerinde, nesillere geçer (ÇOK RİSKLİ!)

**Tartışmalar:**

- Tasarımcı bebekler
- Sosyal eşitsizlik
- Öjeni (genetik seçicilik)
- Doğal evrimin bozulması
- Ekolojik riskler (GDO organizmalar)

## 💡 SORU ÇÖZÜM STRATEJİLERİ

### Strateji 1: mRNA Hesaplama

```
DNA kalıp: 3' - TAC GCA TGC - 5'
           ↓   ↓   ↓   (Tamamlayıcı baz + T→U)
mRNA:      5' - AUG CGU ACG - 3'
```

### Strateji 2: Aminoasit Sayısı

```
1. Toplam nükleotid ÷ 3 = Kodon sayısı
2. UTR bölgelerini çıkar
3. Stop kodonu çıkar (aminoasit değil!)
4. = Aminoasit sayısı
```

### Strateji 3: Mutasyon Analizi

```
1. Yeni DNA/mRNA yaz
2. Kodonları grupla
3. Aminoasitlere çevir
4. Karşılaştır:
   - Aynı AA → Silent
   - Farklı AA → Missense
   - Stop AA → Nonsense
   - Çerçeve kayması → Frameshift
```

### Strateji 4: Prokaryot vs Ökaryot

```
PROKARYOTsızLAR:
- İntron YOK
- Transkripsiyon = Translasyon (eşzamanlı)
- mRNA işleme YOK

ÖKARYOT:
- İntron-Ekson VAR
- Transkripsiyon (çekirdek) ≠ Translasyon (ribozom)
- Splicing, cap, poly-A
```

## 🎯 ÖNEMLİ FORMÜLLER

1. **DNA'da baz sayısı:**

   - A + T + G + C = Toplam nükleotid
   - A = T, G = C
2. **mRNA uzunluğu:**

   - Gen uzunluğu (nükleotid) = mRNA uzunluğu
3. **Protein uzunluğu:**

   - (mRNA nükleotid - UTR'ler) ÷ 3 - 1 (stop) = Aminoasit sayısı
4. **DNA replikasyonu:**

   - 1 DNA → 2 DNA (her biri yarı eski, yarı yeni)
